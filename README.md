# Data Engineering Take-Home Challenge

Welcome! This repository contains everything you need to complete the challenge.

## What's Inside

```
DE-challenge/
├── data/
│   ├── customers.csv      # 50 customers
│   ├── products.csv       # 25 products
│   ├── orders.csv         # 20 000 orders
│   └── order_items.csv    # Line items per order
└── CHALLENGE.md           # Full brief, requirements, and evaluation criteria
```

## Getting Started

1. Read **CHALLENGE.md** carefully before writing any code.
2. The `data/` folder contains the raw CSV files — **do not modify them**.
3. Build your solution in a new folder of your own and submit a link to your GitHub repository.

## Submission

Send your GitHub repository link to your hiring contact before the deadline.  
Make sure the repository is **public** (or share access explicitly if private).

Good luck!
